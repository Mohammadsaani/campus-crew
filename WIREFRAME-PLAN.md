# Wireframe Plan

Draw the screens below in Figma, Excalidraw or on paper. Add arrows to show how a user moves between screens.

1. Welcome screen: name field and Enter button.
2. Dashboard: sidebar, topbar, welcome message, statistics and recently added notes.
3. Notes library: search, semester filter, subject filters and note cards.
4. Upload notes: title, subject, unit, semester, description and file selection.
5. Bookmarks: saved notes and an empty message when no notes are saved.
6. Study groups: group details and Join / Leave buttons.
7. Doubt forum: recent questions and Ask a question form.

Main flow:

```text
Open app
   |
Enter name (first visit)
   |
Dashboard
   |--- Notes Library
   |       |--- Open note
   |       |--- Bookmark / Download
   |       |--- Upload notes
   |
   |--- Bookmarks
   |--- Study Groups
   |--- Doubt Forum
```

Add the final Figma link or exported wireframe image/PDF to the project after the team creates it.
